# Code of Conduct

Octofs follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to every project space: issues, pull requests, discussions, and any other channel where you represent the project.

## Reporting

Report unacceptable behavior privately to contact@muvon.io. The maintainers review every report and keep the reporter's identity confidential.
